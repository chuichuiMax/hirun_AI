# 素材库与 image 桶迁移

## 目标

- 在主导航“工作区”上方新增“素材库”。
- 素材库包含“素材图片”和“封面模板”两个模块。
- 素材库对象统一写入私有 MinIO 桶 `image`，对象路径按用户隔离。
- 复用 `ContentCoverAsset` 保存文件事实，新增素材库目录项保存名称、分类、标签和状态。
- 封面模板继续复用现有大字报分析与封面生成链路。
- 提供可 dry-run、幂等、可校验、可回滚的历史素材迁移工具。

## 范围

- `source` 迁入“素材图片”。
- `template`、`mask`、`poster_template` 迁入“封面模板”。
- `output`、OCR、知识库、头像、工作区和对话附件不迁移。
- 迁移只复制对象并切换数据库引用；旧对象保留，不在本需求中清理。

## 验收清单

- [ ] 新上传素材的 `bucket_name` 恒为 `image`。
- [ ] 对象路径为 `material-library/{owner_uid}/{images|cover-templates}/...`。
- [ ] 两个素材模块均支持上传、列表、搜索、预览和删除。
- [ ] 用户不能访问其他用户的素材。
- [ ] 新封面模板可在现有封面生成中选择和使用。
- [ ] 迁移 dry-run 无写操作，apply 可重复执行，rollback 可恢复原引用。
- [ ] 迁移后素材库有效条目关联的对象全部位于 `image` 桶且哈希一致。
- [ ] 单元、集成、E2E、前端 Lint 与 Build 通过。
