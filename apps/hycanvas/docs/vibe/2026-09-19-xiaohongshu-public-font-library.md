# 小红书模板专区公共字体库

## 需求范围

- 字体能力只属于【视觉创作 → 小红书模板专区】，不把新字体同步到其他设计版块。
- 用户提供的字体包并入该专区原有字体列表。
- 所有已登录用户都可以在专区上传字体。
- 任一用户上传成功后，其他用户都能看到并使用该字体。
- 字体二进制保存在服务端持久化存储中，不写入浏览器 `localStorage`，也不以内嵌 Data URL 的方式塞进设计文件。
- 旧设计中已经存在的 Data URL 字体继续兼容加载。

## 目标

建立一个实例级、但限定于 `xiaohongshu` 专区的公共字体目录，使字体元数据存入 PostgreSQL、字体文件存入 HyCanvas 持久化存储，并同时供浏览器画布和服务端导出渲染使用。

## 验收标准

- [x] 用户 A 在小红书模板专区上传 TTF/OTF 后，用户 B 能在字体列表中看到并使用。
- [x] 刷新页面、重新登录、换浏览器后字体仍存在。
- [x] 重启或重建 HyCanvas 容器后字体仍存在。
- [x] 非小红书设计不显示专区公共字体，也不显示专区上传入口。
- [x] 字体名读取字体文件内部元数据，不依赖上传文件名。
- [x] 相同文件重复上传按 SHA-256 去重，不产生重复字体记录或重复对象。
- [x] 57 MiB 的可变字体通过 multipart 二进制上传，不经过 base64。
- [x] 新设计只保存小型 `library` 字体引用；旧 Data URL 字体仍可打开。
- [x] PNG/PDF 等服务端导出能使用已上传字体渲染文字。

## 验证记录

- 批量扫描 35 个输入文件，按 SHA-256 去重后保留 28 个字体文件，共 333,727,688 字节。
- 浏览器刷新后目录仍返回 28 条；小红书设计显示公共字体和上传入口，普通设计两者均不显示。
- 59,925,144 字节的思源宋体可变版通过真实 multipart 请求返回 201，重复上传前后均为 28 条且复用原记录。
- 使用公共“抖音美好体”的临时设计成功导出 PNG（92,635 字节）和 PDF（123,144 字节），测试设计随后已清理。
- HyCanvas 重启日志确认 `font library restored count=28 zone=xiaohongshu`。
