# 小红书预置字体部署

## 目标

- 将已确认可公开再分发的字体作为 HyCanvas 部署资源随镜像发布。
- 服务启动时按 SHA-256 幂等补齐小红书公共字体库；已有记录和对象直接跳过，存储对象丢失时重新写入。
- 生产镜像和 GitHub Actions 都使用真实字体文件，而不是 Git LFS 指针。

## 资源核对

- 源目录扫描到 32 个 TTF/OTF 文件。
- 按 SHA-256 去重后纳入 25 个唯一文件。
- 唯一文件总大小为 268,448,588 字节；32 个源文件（含重复项）合计 321,092,264 字节。

## 验收清单

- [ ] 25 个字体文件均由 Git LFS 跟踪并能被构建上下文读取。
- [ ] 首次启动导入 25 个字体，重复启动导入 0 个且跳过 25 个。
- [ ] 删除一个持久化对象后重启可补回该对象。
- [ ] HyCanvas 构建、后端测试和 GitHub Actions YAML 校验通过。
